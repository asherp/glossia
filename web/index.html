The Problem: Why PGP Never Went Mainstream

Cryptographic tools are powerful but have terrible UX

PGP has been around for decades, yet most people still send passwords in plain text emails. Why? The UX is hostile to normal workflows.

Base64-armored signatures break email formatting. Hex strings are impossible to read aloud or transcribe. Forwarding an encrypted message turns it into an unreadable mess. The cryptography works—the UX doesn't.

Glossia is the UX layer PGP always needed: Convert ASCII-armored blocks to natural prose, work with them in normal tools, then convert back. Your existing PGP tools still verify signatures—you've just made the transport human-friendly. Forward encrypted messages, read signatures over the phone, paste keys in docs—and it all still decodes perfectly.

How It Works

The encoding pipeline transforms your data through multiple linguistic layers

Input bytes → Codec (bit-pack) → Payload words → CFG + POS slots → Max subsequence → Cover words fill gaps → Natural prose

Decoding is simple: filter the output against the payload wordlist to recover the encoded words, then reverse the bit-packing to get the original bytes. It's guaranteed to work perfectly every time.

Technical Foundation

Built on formal grammar theory and lambda calculus

Under the Hood

  • WASM-powered: Full Rust engine compiled to WebAssembly—runs entirely in your browser at near-native speed
  • Client-side only: No server, no API calls, no tracking. Your data never leaves your device.
  • Context-Free Grammars (CFG): Generate grammatically valid sentence structures
  • Montague Grammar: Lambda calculus ensures type-safe semantic composition
  • POS-based encoding: Payload words fill noun, verb, adjective slots naturally
  • Maximum subsequence matching: Optimal placement of payload words in generated structures
  • Merkle-tree wordlists: Cryptographic proofs for wordlist integrity
  • Multi-language support: English, Czech, Latin, and custom dialects
  • Verifiable and reproducible: Inspect the code on GitHub, build it yourself
