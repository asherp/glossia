Which link is which?

One secret gives every board three things: a public address anyone can open, an author link that lets you publish, and a read key that lets readers decrypt. Share a reader link for read-only access; keep your author link to keep posting. Set a passphrase and the reader link still unlocks it.

What is Glossia?

A readable encoding — not steganography. It doesn't hide that data is present; it makes machine data speakable and transcribable. Skipping steganography's constraints keeps the encoding compact and efficient while staying human-readable.
