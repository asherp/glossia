How it works. A board lives at an npub derived from its signing key. The message is encrypted with a key derived from that same signing key, encoded into Glossia prose, signed, and published to public nostr relays. nsec → post and decrypt; read key → decrypt only; npub → read the prose but not decrypt. You never set a separate password.
Glossia is a readable encoding, not steganography. Encrypted bulletins use authenticated AES-256-GCM, so a wrong key or tampering fails cleanly. A random board key has full entropy; a passphrase-derived board is only as strong as the passphrase (generated ones target ≥128 bits).
