# Introduction

> **Poetry mode (new in v0.6.0).** `glossia --dialect haiku <words>` renders a
> payload as metrical verse — fixed-syllable lines, optionally scanning as
> iambic pentameter. The payload words and their order are untouched, so a poem
> decodes with exactly the command that decodes prose. Five English forms ship:
> `syllabic`, `haiku`, `iambic`, `dactyl` and `anapest` — see
> [Verse Dialects](./verse-dialects.md) for what each one costs.
