How it works. A board lives at an npub derived from a passphrase. Your message is encrypted and encoded into Glossia prose, signed, and published to public nostr relays. The site stays static — anyone opens the board by following its #npub read link. The passphrase is the credential: with it you can post and decrypt; with only the npub others can read the prose but not decrypt it.
Glossia is a readable encoding, not steganography. Encrypted bulletins use authenticated AES-256-GCM, so a wrong passphrase or tampering fails cleanly. Boards are public on nostr; a weak passphrase is offline-guessable. Generated passphrases target ≥128 bits.
