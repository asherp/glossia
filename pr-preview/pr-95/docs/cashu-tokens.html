Glossia Documentation

Cashu Tokens

A Cashu V4 token (cashuB…) encoded into a natural language goes through a compact envelope and canonical encoding, so it gets the canonical form's checksum and Reed–Solomon parity. A few mistyped or misread words (from typing, or OCR of a screenshot) are repaired on the way back.

# token -> prose
echo -n "cashuB..." | glossia --encode --to english

# prose -> token (a greeting or sign-off around the paragraph is ignored)
glossia --decode --to cashu < voucher.txt

From Rust: glossia::cashu_to_words(token, "english", "bip39") and glossia::cashu_from_words(text, "english", "bip39"). From WASM: cashu_to_words(token, language, wordlist) → { encoded_text } and cashu_from_words(text, language, wordlist) → { token, repaired }.

The envelope

A V4 token is CBOR, and each proof's 32-byte secret is stored in it as 64 hex characters. The envelope stores the raw 32 bytes (all lengths one byte):

0x00 cbor..                       a V4 token's CBOR, unchanged (fallback)
0x02 key[32] cbor..               the same, with a mint identity key
0x01 flags len url [key[32]] len unit [len memo]
     nkeysets { len id  nproofs { exp secret[32] C[33] } }

flags bit 0: the URL is written without its https://; bit 1: a memo follows; bit 2: the mint's identity key follows the URL. A proof's amount is 2^exp.

The mint URL and unit are always written. The format assumes no mint and no unit: a default mint would send old tokens to whoever holds that domain later, and a default unit would tie Cashu to one currency.

DLEQ proofs are left out; the receiver checks the token with its mint instead. A token the envelope can't hold exactly (a NUT-10 P2PK/HTLC secret, a witness, an amount that isn't a power of two) is carried as 0x00 raw CBOR, so nothing but DLEQ is ever dropped.

Hashu, whose THH vouchers are Cashu tokens, writes the same envelope (hashu_cli::words), and tests/cashu_vector_*.txt pins the two together.

Mint identity key

A token can carry its mint's identity: the 32-byte x-only (BIP-340) public key of the mint's long-lived root key, written right after the mint URL. A mint URL is only a domain name, and a domain can be lost; the key lets a wallet notice when the URL now points at a server that cannot prove it is the mint that issued the token. The key is not part of the Cashu token: decoding returns a standard cashuB token and hands the key back beside it (CashuDecoded::mint_key). Encode with cashu_to_words_with_mint_key. It costs about 36 English words.

Sizes

Each proof costs 66 bytes, about 100 English words with parity and cover words; the mint URL, unit and any memo cost about 1.4 words per character on top. Measured on tokens from https://mint.hashu.io in unit thh:

ProofscashuB lengthRaw CBOR, canonicalEnvelope, canonical
1217 chars229 words144 words
2362 chars399 words251 words
3510 chars545 words356 words

A 9-character memo, as in the test vector, adds about 20 words.

Before this, a cashuB token went through the character-level crypto/cashu dialect, which spends a byte on every base64 character (464 words for the 2-proof token). That path is still used for V3 cashuA tokens and for verse dialects, and decoding falls back to it for prose an older release wrote.

Privacy

The prose names no mint and does not match the cashu[AB]… pattern that secret scanners, link previews and clipboard watchers look for. It is still a bearer token: whoever can read it and knows it is Glossia can redeem it.
